WAB Research API

Open, anonymized data about the agent-discoverable web. CC-BY-4.0. CORS open. No authentication required.

Endpoints

GET /api/research/stats             # high-level counts
GET /api/research/timeseries?days=30 # daily series
GET /api/research/sample?n=20       # random domain sample

Citing

Please cite as:

Web Agent Bridge Observatory.
  https://webagentbridge.com/research
  Accessed YYYY-MM-DD.

What's not in this dataset

  • No request-level data (no IPs, user agents, referrers, cookies).
  • No per-user analytics.
  • No private manifest content — we only expose the SHA-256 and signed/unsigned status.

Larger exports

For full historical exports (per-domain status over time, signature rotation logs), contact research@webagentbridge.com. Academic use is free; commercial use requires a partner agreement.

Try it

$ curl https://webagentbridge.com/api/research/stats | jq .
